# AMDL

Apple Music 下载工具，支持 Android 和 Windows。需要 Apple Music 订阅。

## 功能

- 下载歌曲和专辑
- 支持 AAC 和杜比全景声
- 写入元数据、封面和 LRC 歌词，支持保存 TTML 歌词

## 构建

- Android：使用 Android Studio 打开仓库根目录。
- Windows：参阅 [Windows 构建说明](windows/README.md)。
